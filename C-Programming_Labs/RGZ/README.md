# РГР. Интерпретатор Brainfuck

## Описание

Программа реализует интерпретатор эзотерического языка программирования Brainfuck на языке C.

Brainfuck использует ленту ячеек и указатель на текущую ячейку. Программа поддерживает команды:

| Команда | Назначение |
|---|---|
| `>` | сдвиг указателя вправо |
| `<` | сдвиг указателя влево |
| `+` | увеличение значения текущей ячейки |
| `-` | уменьшение значения текущей ячейки |
| `.` | вывод символа из текущей ячейки |
| `,` | ввод символа в текущую ячейку |
| `[` | начало цикла |
| `]` | конец цикла |

## Реализовано

- выполнение Brainfuck-программ из файла;
- поддержка команд `> < + - . , [ ]`;
- поддержка вложенных циклов;
- обработка ошибок скобок;
- динамическая лента с расширением вправо;
- защита от выхода указателя влево;
- ограничение максимального количества шагов;
- сохранение состояния ленты в файл;
- отладочный режим с пошаговым выполнением;
- логирование в файл с уровнями `INFO`, `WARNING`, `ERROR`;
- чтение параметров из конфигурационного файла формата `KEY=VALUE`;
- unit-тесты через CMocka;
- сборка проекта через CMake.
